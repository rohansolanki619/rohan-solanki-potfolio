# Data Analyst Portfolio

A professional portfolio website showcasing data analyst skills and projects.

## Project Contents

- **index.html** - Main portfolio website with responsive design
- **extract_pdf.py** - Python utility to extract text from PDF files
- **extracted_dataanalyst.txt** - Extracted content from PDF documents

## Features

- Responsive portfolio website
- Professional data analysis showcases
- PDF text extraction utility
- Clean, modern UI design

## Requirements

- Python 3.7+
- pypdf library (for PDF extraction)

## Installation

```bash
# Install required Python packages
pip install pypdf
```

## Usage

### Extract PDF Content
```bash
python extract_pdf.py
```

This will extract text from the specified PDF file and save it to `extracted_dataanalyst.txt`.

### View Portfolio
Open `index.html` in your web browser to view the portfolio website.

## Getting Started

1. Clone this repository
2. Install dependencies: `pip install pypdf`
3. Run `python extract_pdf.py` to extract PDF content (adjust the PDF path as needed)
4. Open `index.html` in a web browser
